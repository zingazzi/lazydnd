# Custom Monster Storage

LazyDnD now uses `~/.lazydnd/monsters/` for custom monster storage!

## What Changed?

### Before
- Custom monsters stored in `~/.config/lazydnd/custom_monsters/*.json`

### After
- Custom monsters stored in `~/.lazydnd/monsters/*.json`
- Consistent with campaign saves location (`~/.lazydnd/`)
- Easier to find and manage

## Directory Structure

```
~/.lazydnd/
├── monsters/              ← Custom monsters (NEW!)
│   ├── my_dragon.json
│   ├── custom_goblin.json
│   └── frost_giant.json
├── saves/                 ← Campaign saves
│   └── my_campaign.json
└── debug.log             ← Debug log
```

## How to Use

### 1. Create Monsters with the Tool

```bash
./scripts/create_monster.py
# Answer the prompts
# Select "Yes" to save to ~/.lazydnd/monsters/
# Restart LazyDnD
```

### 2. Manually Add Monsters

```bash
# Create a monster JSON file
cat > ~/.lazydnd/monsters/my_monster.json << 'EOF'
[
  {
    "name": "Custom Creature",
    "meta": "Medium humanoid, neutral",
    "Armor Class": "12",
    "Hit Points": "20 (3d8 + 6)",
    "Speed": "30 ft.",
    "STR": "14",
    "STR_mod": "(+2)",
    "DEX": "12",
    "DEX_mod": "(+1)",
    "CON": "14",
    "CON_mod": "(+2)",
    "INT": "10",
    "INT_mod": "(+0)",
    "WIS": "10",
    "WIS_mod": "(+0)",
    "CHA": "10",
    "CHA_mod": "(+0)",
    "Challenge": "1/2 (100 XP)",
    "Actions": "",
    "ActionNumber": 0,
    "ActionList": []
  }
]
EOF
```

### 3. Manage Monsters

```bash
# List all custom monsters
ls -lh ~/.lazydnd/monsters/

# Remove a monster
rm ~/.lazydnd/monsters/unwanted.json

# Edit a monster
nano ~/.lazydnd/monsters/my_monster.json
```

## Migration from Old Location

If you have monsters in the old location:

```bash
# Check if old location exists
if [ -d ~/.config/lazydnd/custom_monsters ]; then
  # Create new location
  mkdir -p ~/.lazydnd/monsters

  # Copy all monsters
  cp ~/.config/lazydnd/custom_monsters/*.json ~/.lazydnd/monsters/

  echo "✅ Monsters migrated to new location!"
fi
```

## Benefits

✅ **Centralized data** - All LazyDnD data in one place (`~/.lazydnd/`)
✅ **One file per monster** - Easier to manage and version control
✅ **Auto-loading** - Drop files in, restart LazyDnD, done!
✅ **Simple backups** - Just backup `~/.lazydnd/`
✅ **Easy sharing** - Share monster files with other DMs

## Notes

- All `.json` files in `~/.lazydnd/monsters/` are loaded automatically
- Custom monsters override default monsters with the same name
- Each file should contain an array with one or more monsters
- Invalid JSON files are skipped with a warning
